# Spine HUD v0.2 Test Release

This is a test release of Spine HUD v0.2.

## Fedora test installation

Extract or clone the release and run:

    ./packaging/install-v0.2-test.sh

Then launch:

    Spine HUD v0.2 Test

from the desktop application menu.

The GUI launcher uses:

    Terminal=false

so Spine HUD does not open a terminal window.

The test installation is isolated from the stable v0.1 PRODUCT:

- application directory:
  `~/.local/share/spine-hud-v0.2-test`
- launcher:
  `~/.local/bin/spine-hud-v0.2-test`
- QSettings application:
  `SpineHUD-DEV`
- log:
  `~/.local/state/spine-hud-v0.2-test/spine.log`

## Remove test installation

Run:

    ./packaging/uninstall-v0.2-test.sh

The uninstall script leaves logs and settings intact.


## v0.2.0-alpha.2 runtime hotfix

Alpha 2 separates the installed test release from the development runtime.

Changes:

- installed releases use `SPINE_ENV=release`
- release settings use `SpineHUD-v0.2`
- release lock uses `spine-hud-v0.2.lock`
- the installed release no longer displays the DEV identity
- stale lock files from dead processes are cleaned before startup
- the private development runtime remains isolated
